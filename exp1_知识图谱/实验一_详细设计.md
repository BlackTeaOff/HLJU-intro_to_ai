## 三、数据设计说明（triples.txt）

领域选「人工智能」本身，贴合课程主线（符号主义 / 连接主义 / 深度学习 / 大模型）。

- **规模**：20 条三元组，20 个实体，5 种关系（提出 / 属于 / 基于 / 提出于 / 击败）。
- **实体类型**（可视化按类型着色）：领域范式（人工智能、机器学习、深度学习、连接主义、符号主义）、模型/技术（Transformer、GPT、AlphaGo、感知机、神经网络）、人物（图灵、McCarthy、Hebb、李世石）、年份（2017）、概念（图灵测试、Hebb 规则、知识图谱、大语言模型）。
- **设计意图**：数据里**故意埋了有向图方向性**的考点——
  - `GPT → 基于 → Transformer → 属于 → 深度学习 → 属于 → 机器学习`（顺着方向，3 跳可通）；
  - `图灵 → 机器学习`：图灵 →图灵测试→人工智能，但「机器学习 → 人工智能」是**反向边**，所以**无有向路径**——这正是题 3 要学生体会的关键点。

## 四、题目设计

### 必做题（3 题，对应 `exp1_scaffold.py` 的 3 处 TODO）

**题 1｜构建有向图 + 可视化（TODO 1）**

- 读取 `triples.txt`，用 `nx.DiGraph()` 构建有向图：实体为节点、关系为有向边，关系名存到边属性 `relation`。
- 运行 `visualize(G)`（教师已给完整绘图代码）生成 `kg_graph.png`。
- 加分点：修改 `node_color()`，用你自己的规则给节点分类着色（如按「人物/模型/领域/年份」）。

**题 2｜一跳相关实体查询（TODO 2）**

- 实现 `related_entities(G, entity)`，返回 `{"out": [...], "in": [...]}`：
  - `out` = 从 entity **出发**的边所指向的实体（`G.successors`）；
  - `in` = **指向** entity 的边所来源的实体（`G.predecessors`）。
- 关键：必须区分方向。例如 `Transformer` 的 `out = [2017, 深度学习]`、`in = [GPT, 大语言模型]`——方向反了语义就错。

**题 3｜路径查询（TODO 3）**

- 实现 `find_path(G, e1, e2)`：有路径返回 `(节点序列, 关系序列)`，无路径返回 `None`。
- 用 `nx.has_path` 判断、`nx.shortest_path` 取节点序列、边属性 `G[u][v]["relation"]` 取关系序列。
- 必跑三个用例并理解结果：`GPT→机器学习`（通）、`图灵→机器学习`（**不通**，体会方向性）、`AlphaGo→李世石`（通）。

### 进阶题（选做加分，作为评 A+ 依据）

**题 4｜实体重要性分析**

- 计算每个实体的「度中心性」（入度 + 出度），排序找出「枢纽实体」。
- 解释为什么它是枢纽（如「人工智能」度 = 5，是所有子概念的汇聚点）。

**题 5｜扩展自己的三元组**

- 在给定数据基础上，自己再设计 5–8 条三元组（延伸「人工智能」领域或自选领域）。
- 说明设计理由：引入了哪些新实体/新关系类型、为什么这样连。

## 八、FAQ（常见问题与教师解答）

1. **中文显示成方块** → `setup_chinese_font()` 已自动选系统可用中文字体（Windows 用微软雅黑 Microsoft YaHei / 黑体 SimHei，macOS 用 PingFang SC，Linux 用 Noto CJK），并有模糊匹配兑底。若个别机器仍乱码，让其打印 `font_manager` 找可用字体。
2. **为什么用 `DiGraph` 而不是 `Graph`** → 关系（属于 / 基于 / 提出）天然有方向，「机器学习→人工智能」和「人工智能→机器学习」语义不同，无向图会丢失这一信息。
3. **题 3「图灵→机器学习」为什么查不到** → 因为边是「机器学习→属于→人工智能」，方向相反；这是**有向图方向性**的核心考点，学生答出「方向不对」即算理解。
4. **关系序列怎么取** → `G[u][v]["relation"]`，遍历 `zip(nodes[:-1], nodes[1:])`。
5. **同一对实体多条边会怎样** → `add_edge` 会覆盖 `relation`，本数据无重复边，若学生自己加重复对要提醒用 `add_edges_from` 并注意属性。
6. **NetworkX 版本差异** → `successors`/`predecessors` 是 `DiGraph` 专属方法，用 `Graph` 会报错，正好强化「有向 vs 无向」。
7. **学生照抄 AI 生成代码怎么办** → 按附录「AI 工具使用规范」执行：重点看报告里「自己对代码的理解」是否真实，能解释 `out`/`in` 区别与方向性即通过。
8. **Windows 能不能跑 / Python 版本** → 能。NetworkX 与 matplotlib 都是纯 Python、跨平台，Windows 上 `pip install networkx matplotlib` 即可。注意最新 networkx 3.6 要求 Python ≥ 3.11，学生用 Anaconda（自带 3.10/3.11）即可；若版本较老，pip 会自动选兼容旧版，本实验用到的 API（DiGraph / add_edge / successors / predecessors / has_path / shortest_path）都是老 API，不受影响。
