## 一、给教师的话（备课速览）

| 项 | 内容 |
|---|---|
| 对应章节 | 第三章 组合优化：搜索、遗传算法与群体智能 |
| 支撑课程目标 | 目标 3（利用搜索、遗传算法、群体智能求解优化问题） |
| 学时 / 分值 | 2 学时（第 13 周）/ 6 分 |
| 依赖 | 纯 Python：`numpy` + `matplotlib`（无需 GPU / 模型 / API） |
| 核心考点 | ① Otsu 类间方差目标函数 ② PSO 位置/速度/适应度 ③ **Otsu 目标函数是「平台」而非单峰**（隐藏难点） |
| 学生产出 | 一份能跑的 Python 脚本 + 分割可视化图 + 收敛曲线 + 实验报告 |

**一句话定位**：用一个「求图像分割阈值」的具体问题，把抽象的「群体智能优化」讲活——穷举（暴力）与 PSO（智能）求解同一个目标函数，学生亲眼看到「30 个粒子迭代几十次就逼近穷举遍历 255 次的最优」。

**三个认知钩子**：
1. **目标函数是核心**：优化问题 = 定义好「目标函数」+ 找一个「寻优算法」。Otsu 的类间方差就是目标函数，PSO 是寻优算法，两者解耦。
2. **PSO 的直观**：粒子 = 候选阈值，速度 = 阈值的变化量，适应度 = 分割质量，「个体最优 + 全局最优」拉着粒子往好解飞。
3. **★平台（最难）**：双峰图两峰之间没有像素，所以 Otsu 目标函数在谷底是**一段平台**——平台内任意阈值分割效果相同。这解释了「为什么 PSO 找到的阈值可能和穷举不完全相等，但适应度一致」。这是本实验最值钱的洞察，务必在题 3 讲透。

## 三、数据设计说明（测试图）

测试图由 `make_test_image()` **程序合成**，保证双峰结构可控：

- 256×256，暗背景 ~60 灰度 + 两个亮圆盘 ~200 灰度 + 高斯噪声（σ=8）。
- 直方图呈**双峰**（峰值 59 和 ~200），谷底在 ~94 附近。
- **设计意图**：双峰图让「Otsu 类间方差最大化」有明确几何意义——阈值落在两峰之间的谷底，把背景和目标分开。同时双峰图的谷底是「平台」，引出题 3 的隐藏考点。

进阶题用 `make_test_image_3class()` 合成**三峰图**（背景 ~40 + 中灰方块 ~130 + 亮圆盘 ~220），让「多阈值分割」有真实的三个类别。

## 四、题目设计

### 必做题（3 题，对应 `exp2_scaffold.py` 的 3 处 TODO）

**题 1｜Otsu 阈值分割：目标函数 + 穷举（TODO 1、TODO 2）**

- **TODO 1** 实现目标函数 `otsu_score(img, t)`：阈值 t 的类间方差 `σ_b² = ω0·ω1·(μ0 − μ1)²`。
- **TODO 2** 实现 `exhaustive_otsu(img)`：穷举 t = 1~254，返回类间方差最大的阈值。
- 运行 `visualize_segmentation(img, t)` 生成三栏图（原图 / 直方图+阈值线 / 分割结果）。

**题 2｜PSO 寻优（TODO 3）**

- 实现 `pso_otsu(img)`：粒子位置 = 阈值，适应度 = `otsu_score`，按 `v ← w·v + c1·r1·(pbest − x) + c2·r2·(gbest − x)`、`x ← x + v` 迭代。
- 参数：30 个粒子、50 代、w=0.7、c1=c2=1.5。

**题 3｜对比 + 说明**

- 对比 PSO 阈值与穷举阈值、PSO 适应度与穷举最优适应度；看 `pso_convergence.png` 的收敛曲线。
- 回答：为什么 PSO 用几十代就逼近穷举的最优？如果阈值不完全相等但适应度相同，说明什么？

### 进阶题（选做加分，作为评 A+ 依据）

**题 4｜多阈值 Otsu + PSO + 二值面分解**

- 用三峰图 `make_test_image_3class()`，把目标函数推广到多阈值 `otsu_score_multi(img, [t1, t2])`（类间方差 = `Σ_c ω_c·(μ_c − μ_T)²`）。
- 实现多阈值 PSO（粒子是 2 维阈值向量），对比穷举 `C(255,2) ≈ 3.2 万` 种组合的最优。
- **二值面可视化**：调用 `visualize_planes(img, thresholds)`（教师已给），把灰度图按阈值分解成多个**二值面**（每个面 = 一个灰度区间，区间内像素为白、其余为黑），逐面打印，直接看到「暗背景层 / 中灰层 / 亮层」各长什么样。
- 观察：多阈值时穷举组合爆炸，PSO 用几百次评估逼近最优——这就是群体智能的价值；同时体会到 **Otsu 不止二值，可以任意多阶分解**。

## 八、FAQ（常见问题与教师解答）

1. **中文显示成方块 / Windows 能不能跑 / Python 版本** → 同实验一：`setup_chinese_font()` 三平台自适应；NetworkX/numpy/matplotlib 均跨平台；建议 Python 3.10+（Anaconda）。
2. **为什么 PSO 阈值和穷举阈值可能不同，但适应度一样** → 双峰图两峰之间（谷底）几乎没有像素，Otsu 类间方差 `σ_b²` 在谷底是**一段平台**：平台内任意阈值，前景/背景划分几乎不变，分割效果相同。所以判 PSO 是否收敛，应看**适应度**而非阈值。这是本实验的隐藏考点。
3. **Otsu 类间方差公式怎么记** → `σ_b² = ω0·ω1·(μ0 − μ1)²`：两类占比越均衡（ω0·ω1 大）、两类均值差越大（μ0−μ1 大），分割越好。直观就是「把两类分得越开、越匀称越好」。
4. **PSO 参数（w / c1 / c2）是什么意思** → w 惯性（保持原方向）、c1 认知（飞向个体最优）、c2 社会（飞向全局最优）。可让学生改大 c1/c2 或粒子数，观察收敛变快/变慢。
5. **粒子位置是浮点数，`otsu_score` 里怎么处理** → 目标函数内先 `t = int(round(t))` 转整数阈值，再算直方图。这样连续寻优也能对离散阈值求适应度。
6. **收敛曲线是平的怎么办** → 说明初始粒子就落进了平台（种子/初始范围问题）。本脚手架已把初始位置设为 `uniform(0, 60)`（集中在低端），保证能看到「从低适应度爬到最优」的过程；让学生理解「初始位置影响收敛过程」。
7. **多阈值为什么可能「过度分割」** → 若在双峰图上做双阈值，Otsu 会把背景噪声再切一刀（切出「背景的低端 vs 背景的高端」），这是 Otsu 多阈值的已知特性。进阶题因此改用三峰图，让多阈值有真实的三个类别。
8. **穷举到底有多慢 / PSO 快在哪** → 单阈值穷举 255 次；K 阈值穷举 `C(255,K)` 组合（K=2 时 3.2 万、K=3 时 ~280 万），组合爆炸；PSO 用「粒子数 × 迭代数」（如 30×50=1500 次评估）逼近最优，这就是群体智能的价值。
9. **什么是「二值面分解」** → 多阈值把灰度分成 K+1 个区间，每个区间一个「二值面」：该区间像素标白(1)、其余标黑(0)。直观就是「把灰度图分层，每层一张二值图」。这体现 **Otsu 不止二值，可任意多阶**；注意它与 ERIS 的「等距多阶」区别——Otsu 多阶阈值是类间方差**自适应**的，ERIS 是**等距**分段。
